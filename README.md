# SmartViz-ML v8

**Explainable Machine Learning for Automated Business Visualization and Decision Support**

PhD research project — BAEL Doctoral Framework — UAC Butembo, DRC

---

## Quick start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Export trained models from notebook (run §22 in SmartViz_ML_v6_fixed.ipynb)
#    → models/ directory will be created automatically

# 3. Launch the app
streamlit run app.py
```

## Model files

Run **§22 — Model Export** in the research notebook to generate `models/`.

Without model files, the app runs in **demo mode** (rule-based fallback) — all pages work but SHAP is unavailable.

---

## Human evaluation

The **Human Evaluation** page collects real Likert ratings (1–5) across 4 dimensions:
- Relevance, Readability, Usefulness, Interpretability

Responses are appended to `human_eval_responses.csv` and can be downloaded directly.
This file is the input for the notebook's §13 human evaluation analysis.

## Design

- **Responsive**: works on mobile, tablet, and desktop
- **Theme**: deep purple sidebar (`#0f0e2e`) + white content + `#6C63FF` accent
- **Typography**: Syne (headings) + Inter (body)
- **Charts**: Plotly with transparent backgrounds
- **No retraining**: models are loaded once and cached (`@st.cache_resource`)

---

## Research context

- **Framework**: BAEL (Behavior-Aware Explainability Loop)
- **Dataset**: Online Retail II — UCI ML Repository
- **Benchmark**: Pool C (300 items, 5 domains, 8 chart types)
- **Primary model**: Random Forest — Pool C Acc@1=0.9500, MRR=0.9688
- **Pool D (held-out)**: Acc@1=0.9615, MRR=0.9776 (gap within ±0.05)
- **Statistical tests**: All-pairs Wilcoxon signed-rank (RF > all others, p<0.01)
